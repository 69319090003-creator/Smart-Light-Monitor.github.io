ABOUT PROJECT

เกี่ยวกับโครงงาน

แนวคิดและที่มาของระบบ Smart Light Monitor

💡 หลักการและเหตุผล

Smart Light Monitor เป็นโครงงานที่พัฒนาขึ้น เพื่อใช้ตรวจวัดระดับความสว่างของสภาพแวดล้อม โดยใช้ LDR Sensor ในการตรวจจับปริมาณแสง และใช้บอร์ด ESP32-2432S028 เป็นตัวประมวลผลข้อมูล


ค่าที่ได้จากเซนเซอร์จะถูกนำมาประมวลผล และแปลงเป็นระดับเปอร์เซ็นต์ความสว่าง จากนั้นแสดงผลบนหน้าจอ TFT เพื่อให้ผู้ใช้งานสามารถตรวจสอบ ระดับแสงได้อย่างสะดวก

🎯 แนวคิดของโครงงาน

ระบบถูกออกแบบให้มีโครงสร้างเรียบง่าย ใช้อุปกรณ์จำนวนน้อย และสามารถนำไปต่อยอด กับระบบ Smart Home หรือระบบควบคุม แสงสว่างอัตโนมัติได้ในอนาคต


โครงงานยังเป็นการประยุกต์ใช้ความรู้ด้าน Microcontroller, Sensor และ Embedded System เพื่อสร้างอุปกรณ์ ตรวจวัดที่สามารถใช้งานได้จริง

HOW IT WORKS

หลักการทำงาน

ขั้นตอนการทำงานของระบบ Smart Light Monitor

01

ตรวจจับแสง

LDR Sensor ตรวจจับ ปริมาณแสงจากสภาพแวดล้อม

02

รับข้อมูล

ESP32 รับค่าจาก LDR ผ่านขา Analog Input

03

ประมวลผล

ระบบนำค่า ADC มาแปลงเป็นระดับความสว่าง

04

แสดงผล

แสดงค่าเปอร์เซ็นต์ และสถานะบนหน้าจอ TFT
