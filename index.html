แผนกวิชา: เทคโนโลยีคอมพิวเตอร์

สถานศึกษา: วิทยาลัยเทคนิคตรัง

หลักการและเหตุผล

Smart Light Monitor เป็นโครงงานที่พัฒนาขึ้นเพื่อใช้ตรวจวัด ระดับความสว่างของสภาพแวดล้อม โดยใช้เซนเซอร์ LDR ในการตรวจจับปริมาณแสง และใช้บอร์ด ESP32-2432S028 เป็นตัวประมวลผลและแสดงผลข้อมูลบนหน้าจอ TFT

ระบบสามารถนำค่าที่ตรวจวัดได้มาประเมินระดับความสว่าง และแสดงผลให้ผู้ใช้งานสามารถตรวจสอบได้ง่าย

อุปกรณ์ที่ใช้

  • ESP32-2432S028
  • LDR Sensor
  • สาย Jumper
  • แหล่งจ่ายไฟ / USB

หลักการทำงาน

  1. LDR Sensor ตรวจจับปริมาณแสงในบริเวณนั้น
  2. ESP32 รับค่าจากเซนเซอร์และประมวลผลข้อมูล
  3. ระบบนำค่าที่ได้มาประเมินระดับความสว่าง
  4. แสดงผลระดับความสว่างบนหน้าจอ TFT

คุณสมบัติของโครงงาน

  • ตรวจวัดระดับแสงในสภาพแวดล้อม
  • แสดงข้อมูลบนหน้าจอ TFT
  • ใช้จำนวนอุปกรณ์ไม่มาก
  • สามารถนำไปประยุกต์ใช้กับระบบ Smart Home ได้
  • สามารถต่อยอดเป็นระบบควบคุมไฟอัตโนมัติได้

ประโยชน์ที่ได้รับ

โครงงานช่วยให้ผู้ใช้งานสามารถตรวจสอบระดับความสว่าง ของพื้นที่ได้สะดวก และเป็นพื้นฐานสำหรับการพัฒนาระบบ Smart Home หรือระบบควบคุมแสงสว่างอัตโนมัติในอนาคต

นอกจากนี้ยังช่วยให้ผู้จัดทำได้เรียนรู้การเขียนโปรแกรม ESP32 การอ่านค่าจากเซนเซอร์ และการแสดงผลข้อมูล บนหน้าจอ TFT
